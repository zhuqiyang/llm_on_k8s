# Ray Serve

## 安装 kubeRay

```bash
# 添加 kubeRay 的 Helm 仓库
helm repo add kuberay https://ray-project.github.io/kuberay-helm/

# 拉取 operator 的 chart 包
helm pull kuberay/kuberay-operator

# 解压 chart 包
tar -xf kuberay-operator-1.7.1.tgz

# 安装到 ray-system 命名空间
helm install kuberay-operator . -n ray-system
```

## 部署 Ray 集群

```yaml
# 生成 raycluster.yaml 配置文件
cat >> raycluster.yaml <<EOF
apiVersion: ray.io/v1
kind: RayCluster
metadata:
  name: raycluster-gpu             # 集群名称
spec:
  rayVersion: "2.40.0"             # 请与镜像版本保持一致
  enableInTreeAutoscaling: false   # 单 Worker 节点，无需自动伸缩

  # ---------- Head 节点：master（无 GPU）----------
  headGroupSpec:
    serviceType: ClusterIP          # 如需外部访问 Dashboard，可改为 NodePort
    rayStartParams:
      dashboard-host: "0.0.0.0"     # 允许外部访问 Dashboard
      num-gpus: "0"                 # 确保 Head 不请求 GPU
    template:
      spec:
        nodeSelector:
          kubernetes.io/hostname: master   # 固定调度到 master 节点
        tolerations:
          - key: "node-role.kubernetes.io/master"
            operator: "Exists"
            effect: "NoSchedule"
          - key: "node-role.kubernetes.io/control-plane"
            operator: "Exists"
            effect: "NoSchedule"
        containers:
          - name: ray-head
            image: rayproject/ray:2.40.0
            resources:
              limits:
                cpu: "2"
                memory: "4Gi"
              requests:
                cpu: "2"
                memory: "2Gi"
            ports:
              - containerPort: 6379
                name: gcs           # 全局控制服务端口
              - containerPort: 8265
                name: dashboard     # Dashboard 端口
              - containerPort: 10001
                name: client        # 客户端连接端口

  # ---------- Worker 节点：worker2（有 GPU）----------
  workerGroupSpecs:
    - groupName: gpu-worker
      replicas: 1                   # Worker 副本数
      minReplicas: 1
      maxReplicas: 1
      rayStartParams: {}
      template:
        spec:
          nodeSelector:
            kubernetes.io/hostname: worker2   # 固定调度到 worker2 节点
          # 如果 worker2 存在污点，请取消注释并填入实际污点键
          # tolerations:
          #   - key: "nvidia.com/gpu"
          #     operator: "Exists"
          #     effect: "NoSchedule"
          containers:
            - name: ray-worker
              image: rayproject/ray:2.40.0-gpu   # 必须使用 GPU 镜像
              resources:
                limits:
                  nvidia.com/gpu: "1"            # 申请 1 块 GPU
                  cpu: "4"
                  memory: "8Gi"
                requests:
                  nvidia.com/gpu: "1"
                  cpu: "2"
                  memory: "4Gi"
EOF
```

## 暴露 Dashboard（Ingress）

`rayserve.local.yaml` 内容如下：

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: raycluster.local                  # Ingress 名称
  namespace: default                      # 与 Ray 集群所在命名空间一致
spec:
  ingressClassName: nginx                 # 使用 nginx-ingress
  rules:
    - host: raycluster.local              # 访问域名
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: raycluster-gpu-head-svc   # Head 节点的 Service 名称
                port:
                  number: 8265                  # Dashboard 端口
```
