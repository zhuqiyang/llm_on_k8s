# 14. APISIX 网关

## 架构

```
                外部用户
                   │
                   │ http://apisix-grafana.local
                   ▼
    ┌──────────────────────────────┐
    │  apisix-gateway (LoadBalancer)│
    │  EXTERNAL-IP: 192.168.0.150   │  ← 数据面，处理业务流量
    └──────────────┬───────────────┘
                   │ 读取路由/上游配置
                   ▼
    ┌──────────────────────────────┐
    │      apisix-etcd (2379)       │  ← 配置存储
    └──────────────▲───────────────┘
                   │ 写入配置
    ┌──────────────┴───────────────┐
    │ apisix-ingress-controller     │  ← 控制面，翻译 K8s 资源
    │  (监听 Ingress / ApisixRoute) │
    └──────────────┬───────────────┘
                   │ 调用 Admin API 下发
                   ▼
    ┌──────────────────────────────┐
    │    apisix-admin (9180)        │  ← 管理接口，仅集群内
    └──────────────────────────────┘
                   │
        apisix-etcd-headless          ← etcd 集群内部节点发现
```

## 组件说明

- **apisix-gateway**：APISIX 数据面入口，真正处理外部业务流量的地方。所有外部请求从这里进入，APISIX 根据路由规则转发给后端服务。
- **apisix-ingress-controller**：负责把 Kubernetes 资源翻译成 APISIX 配置，监听集群中的 `Ingress`、`ApisixRoute`、`ApisixUpstream`、`ApisixTls` 等资源，转换成 APISIX 配置，通过 `apisix-admin` 下发到 APISIX。

## 安装

```bash
helm repo add apisix https://charts.apiseven.com

helm pull apisix/apisix

tar -xf apisix-2.17.0.tgz

cd apisix

helm install apisix . \
  --namespace ingress-apisix \
  --create-namespace \
  --set ingress-controller.enabled=true \
  --set ingress-controller.apisix.adminService.namespace=ingress-apisix \
  --set ingress-controller.gatewayProxy.createDefault=true \
  --set etcd.persistence.enabled=true \
  --set etcd.persistence.storageClass="openebs-hostpath" \
  --set etcd.persistence.size="2Gi" \
  --set gateway.type=LoadBalancer \
  --set apisix.ssl.enabled=true \
  --set gateway.loadBalancerIP=192.168.0.151
```

> `--set apisix.ssl.enabled=true`：为 Gateway Service 增加 443 端口映射。

## Ingress 示例

```bash
cat >> apisix-grafana.local.yaml <<'EOF'
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: apisix-grafana.local
  namespace: monitoring
spec:
  ingressClassName: apisix # 这里选用 apisix
  rules:
  - host: apisix-grafana.local
    http:
      paths:
      - backend:
          service:
            name: grafana
            port:
              number: 80
        path: /
        pathType: Prefix
EOF
```
