# sglang 开启 OpenTelemetry

> 这里只是演示，没有使用 agent，直接将数据传输到 `otel-gateway-opentelemetry-collector`，再由 collector 转发到后端存储 Jaeger 及其查询 UI。

数据流向：

```
sglang -> gateway-collector -> Jaeger -> Jaeger Query UI
```

---

## 1. 安装 gateway collector

```bash
helm repo add open-telemetry https://open-telemetry.github.io/opentelemetry-helm-charts

# 下载包到本地
helm pull open-telemetry/opentelemetry-collector

tar -xf opentelemetry-collector-*.tgz
```

配置文件：

```bash
cat >> gateway-values.yaml <<EOF
mode: deployment
image:
  repository: "otel/opentelemetry-collector-contrib"

config:
  receivers:
    otlp:
      protocols:
        grpc:
          endpoint: 0.0.0.0:4317
        http:
          endpoint: 0.0.0.0:4318
  processors:
    batch: {}
  exporters:
    # 将 trace 转发到 Jaeger（Jaeger v2 也使用 OTLP 协议接收）
    otlp/jaeger:
      endpoint: jaeger.observability.svc.cluster.local:4317
      tls:
        insecure: true
  service:
    pipelines:
      traces:
        receivers: [otlp]
        processors: [batch]
        exporters: [otlp/jaeger]

ports:
  otlp:
    enabled: true
    containerPort: 4317
    servicePort: 4317
  otlp-http:
    enabled: true
    containerPort: 4318
    servicePort: 4318
EOF

cp gateway-values.yaml opentelemetry-collector/
cd opentelemetry-collector/

helm install otel-gateway . \
  --values gateway-values.yaml \
  --namespace observability
```

## 2. 安装 Jaeger

```bash
helm repo add jaegertracing https://jaegertracing.github.io/helm-charts

helm pull jaegertracing/jaeger

tar -xf jaeger-*.tgz

cd jaeger
```

配置文件：

```bash
cat >> jaeger-v2-values.yaml <<EOF
# 启用 All-in-One 模式
allInOne:
  enabled: true

# 关键：使用 v2 的 OTel 配置语法
config:
  service:
    extensions: [jaeger_storage, jaeger_query]
    pipelines:
      traces:
        receivers: [otlp]
        processors: [batch]
        exporters: [jaeger_storage_exporter]
  extensions:
    # 使用内存存储，最多保存 10w 条 trace
    jaeger_storage:
      backends:
        memory_store:
          memory:
            max_traces: 100000
    jaeger_query:
      storage:
        traces: memory_store
  receivers:
    otlp:
      protocols:
        grpc:
          endpoint: 0.0.0.0:4317
        http:
          endpoint: 0.0.0.0:4318
  processors:
    batch: {}
  exporters:
    jaeger_storage_exporter:
      trace_storage: memory_store
EOF
```

安装：

```bash
helm install jaeger . \
  --namespace observability \
  -f jaeger-v2-values.yaml
```

配置 Ingress（用于通过 `jaeger.local` 访问 UI）：

```bash
cat >> jaeger.local.yaml <<EOF
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  generation: 2
  name: jaeger.local
  namespace: observability
spec:
  ingressClassName: nginx
  rules:
  - host: jaeger.local
    http:
      paths:
      - backend:
          service:
            name: jaeger
            port:
              number: 16686
        path: /
        pathType: Prefix
status:
  loadBalancer:
    ingress:
    - ip: 192.168.0.150
EOF
```

## 3. sglang 的配置

Dockerfile（安装 OpenTelemetry 依赖并启用 tracing，老版本sglang镜像需要，新版本不需要安装）：

```dockerfile
FROM harbor.local:80/sglang/sglang:latest

ENV PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
ENV PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn

RUN pip install --no-cache-dir \
    opentelemetry-sdk \
    opentelemetry-api \
    opentelemetry-exporter-otlp \
    opentelemetry-exporter-otlp-proto-grpc \
    "protobuf>=7.35.1,<8.0.0"

WORKDIR /sgl-workspace/sglang
RUN pip install --no-cache-dir -e "python[tracing]"
```

sglang 容器配置（关键启动参数）：

```yaml
      containers:
      - name: sglang
        image: lmsysorg/sglang:latest
        command: [python3, -m, sglang.launch_server]
        args:
          - --served-model-name
          - qwen2.5-coder-3b-instruct-awq
          - --model-path
          - /data/models/Qwen/Qwen2.5-Coder-3B-Instruct-AWQ
          - --quantization=awq
          - --context-length=32768
          - --enable-trace # 开启链路追踪
          - --otlp-traces-endpoint=otel-gateway-opentelemetry-collector.observability.svc.cluster.local:4317 # 指定 gateway-collector 地址
          - --tp-size=1
          #- --mem-fraction-static=0.7
          - --enable-metrics
          - --enable-mfu-metrics
          - --host=0.0.0.0
          - --port=30000
```

> 详见 `yaml/Qwen2.5-Coder-3B-SGLang-OpenTelemetry/` 目录里的资源。
